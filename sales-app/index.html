TRAINING & HELP

How to use BusterBuild Sales

1. Scan / Find

Scan the shelf QR or search the catalogue by product name or code.

2. Smart Measure

Select layout and waste allowance, enter room size, then save multiple rooms if needed.

3. Build Cart

Add the calculated m², recommended extras, sanitary items or a custom combo.

4. Create Estimate

Select an existing customer or enter a new one, set validity and permitted discount, then save.

5. Follow Up

Send the PDF, mark the estimate Sent, then use follow-up reminders after two days.

6. Convert

When confirmed, capture the customer confirmation and official sales-system reference.
